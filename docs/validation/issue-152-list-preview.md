## 方法与证据边界

- 同一 Windows 主机、同一独立 Chrome `154.0.8037.98` 会话，1280×960 viewport；每版本每面板 5 轮，取中位数。基线先执行，再执行当前版本；模块加载在计时前完成。这不是冷启动或统计显著性实验。
- 固定合成数据：题库 100 条、回收站 100 条、历史 50 条。覆盖长文、多公式、四类定界符、语法错误、未闭合及 Markdown 图片/链接内图片。Axios adapter 模拟列表/详情接口，执行真实 Vue 面板、真实搜索源选择器、真实摘要扫描/renderer/cache；无真实账号、数据库、网络延迟或 OCR/LLM。
- 首屏测量从组件 mount 到两帧后的列表展示；回收站包括先挂载题库再首次进入回收站。搜索测量为题干/答案/解析三次输入到两帧后的可见摘要响应之平均；另等待既有防抖接口刷新，未将网络往返独立计时。勾选计时包括两帧稳定展示。
- KaTeX 和 MarkdownIt 实际调用计数分别记录；搜索首次 Vue 更新应仅解析变化后的实际摘要源（原文兜底不调用 MarkdownIt），后续列表接口刷新允许重建。勾选和创建试卷弹窗不应新增两类调用。
- 列表阶段检查图片 API 调用与 DOM；整个页面执行还用 CDP 检查远程图片请求。详情允许既有独立图片 Blob 加载，不计为列表流量。图片计数不能代表总网络字节或完整流量性能。
