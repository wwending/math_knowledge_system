# Math Knowledge 用户使用说明书

> 适用版本：以管理员提供的网站为准。
> 核对日期：2026-08-30。

本说明书面向高中教师和学生，介绍当前网站中已经可以直接使用的功能。界面中的主要导航依次为“题目录入”“智能题库”“历史记录”“组卷”和“反馈中心”。

## 使用前先了解

Math Knowledge 是一个按登录账号隔离的题目录入、个人题库和组卷工具。每个普通账号只能看到和管理自己的题目、试卷与反馈。

- 教师可以录入题目、整理自己的题库、选择题目组卷并导出 PDF。
- 学生可以用自己的账号整理错题、查看和修改自己的题目、生成个人练习卷并反馈问题。
- “学生”和“教师”是使用场景，不是当前系统中的班级关系。系统目前没有学生在线作答或提交、教师布置或发布、班级管理、共享题库等功能。
- OCR 和 AI 整理结果只是草稿。系统不会自动把识别结果直接写入题库，必须由当前用户核对并点击“保存入题库”。

## 1. 登录、注册与密码

### 登录

1. 打开网站登录页。
2. 输入手机号和密码，点击“登录”。
3. 如果账号被要求首次改密，先按页面提示设置新密码，再进入首页。

该网站当前不提供短信登录或自助找回密码。如果忘记密码，请联系管理员重置。账号被停用时也需要联系管理员。

### 注册

该网站当前关闭自主注册。新用户不能自行创建账号，请联系管理员开通；忘记密码也请联系管理员重置。

若以后登录页的账号提示发生变化，以届时页面提示为准；页面暂时无法获取账号能力状态时，请稍后重试或联系管理员，不要反复提交。

## 2. 教师常用流程

推荐按以下顺序操作：

1. 在“题目录入”上传图片或 PDF。
2. 选择处理方式并等待识别。
3. 对照题目原图，逐题检查并修改结果。
4. 确认配图和风险提示后，保存入题库。
5. 在“智能题库”搜索、查看或编辑题目。
6. 勾选题目创建试卷，在“组卷”中调整顺序、分值和显示设置。
7. 预览作业并导出 PDF。

## 3. 学生常用流程

学生使用的是同一套个人工具，常见用法是：

1. 上传自己的错题图片，或从 PDF 中选择包含错题的一页。
2. 使用“裁剪识别”只保留目标题；同一页有多道错题时使用“批量分题”。
3. 对照原图修正公式、选项和题目条件，再保存到自己的题库。
4. 在题库中搜索知识点或题目文字，选题生成个人练习卷。
5. 关闭答案和解析完成练习；需要核对时再打开答案或解析并重新预览、导出。

当前没有在线答题和答案提交入口。导出的 PDF 需要在线下打印、书写或自行保存。

## 4. 图片与 PDF 题目录入

### 选择文件

进入“题目录入”，点击上传区域或把文件拖入其中。当前界面接受 JPG、JPEG、PNG 和 PDF。

- 图片会直接进入“图片确认”。
- PDF 会先显示页面缩略图。点击要处理的那一页后，再选择识别方式。
- 当前一次处理一个 PDF 页面；处理另一页时需要返回选页并再次选择。
- PDF 无法解析时，文件可能已加密或损坏，可尝试另存为普通 PDF，或把目标页导出为清晰图片后上传。

### 选择识别方式

- **整页识别**：适合页面中只有一道完整题目。
- **裁剪识别**：适合只需要页面中的一部分。拖动和缩放图片，让裁剪框完整包含题干、条件、选项和配图，再点击“确认裁剪并上传”。
- **批量分题**：适合同一页有多道题。按页面提示逐题框选，确认后系统会分别识别；每道题可以单独重试、编辑和保存。

批量分题时不要把一道题拆成两个框，也不要漏掉跨栏选项、题目下半部分或与题目相关的图形。

## 5. 核对 OCR 与 AI 整理结果

识别完成后，页面会同时提供题目原图和整理结果。请至少检查：

1. 题目条件、问法和结论是否完整。
2. 数字、正负号、上下标、根号、分数、角标和公式是否正确。
3. 选择题的 A、B、C、D 等选项是否齐全且顺序正确。
4. 点名、线段名、函数名和变量名是否与原图一致。
5. AI 是否误补条件、改写题意或把常见题型内容代入本题。

需要修改时点击“编辑识别结果”，可直接修改 Markdown / LaTeX 文本并查看预览。展开“识别调试信息”可以比较“原始 OCR 文本”和“LLM 清洗文本”，帮助判断错误来自哪一步。

如果出现“识别风险提示”，保存时系统会再次确认。风险提示只能帮助发现部分问题，不能保证没有漏识别或误识别。若 AI 整理失败但 OCR 已完成，页面可能展示降级结果；仍需人工核对后才能决定是否保存。

只有点击“保存入题库”后，题目才成为正式题库数据。不要在尚未核对时点击“仍然保存”。

## 6. 题目配图

系统会尝试检测几何图形、坐标图、表格等题目配图。确认页会显示检测框：

- 可以移动、缩放、删除、清空或重置已有检测框。
- 检测到多张有效配图时，可以一并保存。
- 检测框明显重叠、过小或越界时，页面会阻止保存，请先修正。
- 未检测到配图或检测服务暂不可用时，可以按纯文字题保存，但应先确认题目是否会因此缺失必要信息。

题目入库后，在题目编辑页可以维护题干、答案、解析的文字块和图片区，裁取多张配图，并调整配图在图片区中的位置与大小。编辑时应保持数学含义和原题一致；保存失败或发生版本冲突时，页面会保留当前草稿供继续处理。

“题目区域图”是用于核对的完整题目来源图，“题目配图”是题内的图形或表格，两者不是同一内容。

## 7. 智能题库

### 搜索与查看

进入“智能题库”后，只会看到当前登录账号的题目。搜索框可按题干、答案、解析或知识点查找；命中时列表会提示命中位置。题目较多时列表只显示前若干条，应使用更具体的关键词缩小范围。

点击题目卡片或“查看详情”，可查看来源图、知识点以及“题目内容”“答案”“解析”三个区段。题内多张配图会按保存的布局显示。

### 编辑题目

在有效题目的详情中点击“编辑题目”，可进入独立编辑页：

- 修改题干、答案、解析、知识点、题型和难度。
- 调整文字块顺序或移动到其他区段。
- 维护题目配图及其布局。
- 离开有未保存修改的页面时，系统会提醒确认。

保存后题库使用新版本。已经加入试卷的题目不会跟着改变，详情见“试卷快照”。

### 回收站

在题库列表点击“删除”，题目会进入“回收站”，并保留 30 天。回收站中可以：

- 查看已删除题目的基本内容；
- 点击“恢复”放回题库；
- 点击“永久删除”执行不可恢复的用户侧删除。

永久删除前请认真确认。删除或修改题库原题不会改写已经创建的历史试卷快照。

### 识别历史

“历史记录”用于查看识别产生的题目记录、来源图和 AI 识别分析结果。它是查看入口，不是重新编辑旧识别流程的入口；需要维护正式题目时请进入“智能题库”。

## 8. 创建和编辑试卷

### 从题库创建

1. 在“智能题库”勾选需要的题目。
2. 点击“创建试卷”。
3. 填写必填的试卷标题和可选说明，确认创建。
4. 页面会切换到“组卷”。

### 编辑试卷

在“组卷”中选择一份试卷，点击“编辑试卷”，可以：

- 修改标题和说明；
- 从自己的题库继续添加题目；
- 删除卷内题目、上移或下移题序；
- 设置每题分值；
- 打开或关闭答案、解析。

试卷至少保留一道题。存在未保存修改时，先点击“保存修改”再正式导出 PDF。

### 试卷快照

题目加入试卷时，题干、答案、解析和配图会冻结为该试卷的快照。之后即使修改或删除题库原题，已有试卷内容也不会自动变化。

如果希望试卷使用题目的新版本，请在编辑试卷时移除旧题，再从题库重新添加。这个设计用于保证历史试卷内容稳定。

## 9. 预览、答案解析与 PDF 导出

在试卷详情中：

1. 选择“无答题区”或“每题后留白”。
2. 根据用途打开或关闭“显示答案”“显示解析”。显示答案或解析时，作答区会暂时隐藏。
3. 点击“预览作业”，检查题序、分值、公式、配图、分页和显示内容。
4. 在预览上方点击“打印/导出 PDF”，等待文件生成并开始下载。

建议给学生的练习卷关闭答案和解析；教师留档或学生订正时可以打开。导出前务必先保存试卷修改，否则页面会阻止导出。复杂长题、超大配图或网络问题可能导致导出失败，可先缩减内容、检查图片，再重试。

## 10. 反馈中心

所有登录用户都可以进入“反馈中心”。

1. 点击“提交反馈”。
2. 选择“问题”“需求”或“建议”。
3. 输入不超过 500 字的描述。
4. 可添加最多 5 张 JPG、JPEG 或 PNG 截图，然后提交。

普通用户只能看到自己的反馈；反馈仅提交者本人和管理员可见。待处理状态的反馈可以编辑或撤回，撤回会同时删除反馈和截图且无法恢复。管理员处理后，用户可以看到“已采纳”或“已拒绝”状态及处理说明。

提交截图前请遮盖学生姓名、手机号、考试编号、学校内部信息等无关隐私。

## 11. 隐私与数据边界

- 题目、来源图、题目配图、试卷和普通用户反馈都按登录账号控制访问。
- 不要共用账号；使用公共电脑后应退出登录，不要让浏览器长期保存账号密码。
- 上传前应确认自己有权处理相关试卷、讲义和图片。
- 尽量裁掉姓名、学号、学校、二维码和无关页面区域，只保留解题所需内容。
- 不要在题目或反馈中填写密码、验证码、密钥等敏感信息。
- 账号隔离不等于共享功能：当前没有把个人题库发布给其他用户的入口。

## 12. 常见问题与故障处理

### 登录失败或页面提示登录失效

先确认手机号和密码；失败次数过多时等待一段时间再试。登录状态失效时返回登录页重新登录。账号不可用或忘记密码请联系管理员。

### PDF 页面不显示或解析失败

确认 PDF 未加密且文件可以正常打开。可尝试另存为新 PDF，或把目标页导出为清晰的 JPG/PNG。当前每次只选择并处理一页。

### OCR、AI 整理或图片检测失败

保留页面上的错误提示；尝试使用更清晰、摆正、无遮挡的图片，并裁到完整题目。AI 整理失败时可根据页面给出的 OCR 降级结果人工修改。未检测到配图时，不要把含必要图形的题目误存成纯文字题。

### 公式、选项或题意不正确

不要直接入库。对照“题目原图”，展开“识别调试信息”，修改后再保存。双栏选择题、复杂公式、几何题和低清图片需要特别仔细核对。

### 保存按钮不可用或保存失败

检查识别是否已经完成、题目内容是否为空、配图框是否重叠或越界。若提示版本冲突，保留当前草稿，对照最新题目后再决定如何修改。重复保存同一识别草稿会被拒绝，可到题库确认是否已经入库。

### 找不到题目

确认当前登录的是原来录入题目的账号；清空或缩短搜索词，并检查“题库”和“回收站”两个页签。列表达到显示上限时应使用更具体的题干、答案、解析或知识点关键词。

### PDF 导出失败或内容不完整

先保存所有试卷修改，再重新预览。检查公式、配图和长题分页；网络恢复后重试。如果仍失败，请到“反馈中心”提交问题，并附上不含敏感信息的界面截图和可复现步骤。

## 当前没有的功能

为避免误解，当前系统不提供：

- 学生在线作答、提交答案或自动批改；
- 教师向学生布置、发布或回收作业；
- 班级、课程、师生关系管理；
- 用户之间共享或协作维护题库；
- DOCX 导出；
- 一次把整份多页 PDF 自动拆成全部题目并连续入库。

如需要这些能力，可在“反馈中心”提交需求，但提交反馈不代表功能已经排期或上线。
